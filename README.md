# 🏥 Clínica Vida Nova

Landing Page estática desenvolvida para uma clínica de saúde fictícia como parte da disciplina de **Programação e Desenvolvimento Web**.

O projeto apresenta uma interface moderna e responsiva para uma clínica que oferece diferentes serviços relacionados à saúde, incluindo atendimento médico, exames laboratoriais e de imagem e aconselhamento nutricional.

---

## 📋 Sobre o Projeto

A **Clínica Vida Nova** é uma clínica de saúde fictícia criada para o desenvolvimento deste projeto acadêmico.

A Landing Page tem como objetivo apresentar a clínica, seus principais serviços, sua equipe profissional e disponibilizar um formulário estático para contato.

O projeto foi desenvolvido utilizando apenas **HTML5 e CSS3**, sem utilização de backend ou processamento de dados do formulário.

---

## 🎯 Objetivos

O projeto tem como principais objetivos:

* Desenvolver uma página web estática utilizando HTML5;
* Aplicar conceitos de estilização utilizando CSS3;
* Utilizar HTML semântico para estruturar o conteúdo;
* Criar uma interface visualmente organizada e agradável;
* Desenvolver um layout responsivo para diferentes tamanhos de tela;
* Apresentar serviços e profissionais de uma clínica fictícia;
* Implementar um formulário estático de contato.

---

## ✨ Funcionalidades

A Landing Page possui as seguintes seções:

### 🏠 Início

Apresentação da Clínica Vida Nova, acompanhada de uma imagem representando o ambiente da clínica.

### 🩺 Serviços

Apresentação dos principais serviços oferecidos pela clínica:

* Atendimento Médico;
* Exames Laboratoriais e de Imagem;
* Aconselhamento Nutricional.

Cada serviço possui uma imagem, título e descrição.

### 👥 Equipe

Apresentação de três profissionais fictícios:

* **Dr. Gabriel Almeida** — Clínico Geral;
* **Dra. Mariana Costa** — Nutricionista;
* **Dr. Rafael Martins** — Radiologista.

Cada profissional possui uma fotografia, nome, cargo e descrição.

### 📬 Contato

Formulário estático contendo os seguintes campos:

* Nome;
* E-mail;
* Cidade;
* Estado.

O formulário não possui processamento ou integração com um servidor.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

* **HTML5** — estrutura e conteúdo da página;
* **CSS3** — estilização e layout;
* **Flexbox** — organização dos elementos;
* **CSS Grid** — estruturação de elementos quando aplicável;
* **Media Queries** — responsividade;
* **Git** — controle de versão;

## ▶️ Como Executar

Por se tratar de uma página estática, não é necessário instalar dependências ou configurar um servidor.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd landing_page_clinica_vida_nova
```

### 3. Abra o arquivo `index.html`

O arquivo pode ser aberto diretamente em um navegador:

```text
index.html
```

Também é possível utilizar extensões como **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.

## 📱 Responsividade

A página foi desenvolvida para se adaptar a diferentes tamanhos de tela.

Foram utilizados **Media Queries** para adaptar o layout para:

* 💻 Computadores;
* 💻 Notebooks;
* 📱 Tablets;
* 📱 Smartphones.

Em telas menores, os elementos que originalmente aparecem lado a lado são reorganizados verticalmente para proporcionar uma melhor experiência de navegação.

---

## 🎨 Identidade Visual

A identidade visual foi desenvolvida utilizando principalmente tons associados à área da saúde, como azul, verde e branco.

A paleta busca transmitir:

* Confiança;
* Segurança;
* Profissionalismo;
* Saúde;
* Tranquilidade.

As cores principais foram organizadas utilizando **variáveis CSS**, facilitando futuras alterações na identidade visual do projeto.

---

## 🖼️ Imagens

As imagens utilizadas no projeto foram obtidas a partir do **Pexels**, utilizando fotografias disponibilizadas para uso gratuito.

As imagens foram utilizadas para representar:

* Ambiente da clínica;
* Atendimento médico;
* Exames laboratoriais;
* Aconselhamento nutricional;
* Profissionais da equipe.

Os arquivos foram armazenados localmente na pasta `img/` para manter o projeto organizado e permitir que a página seja executada sem depender do carregamento de imagens externas.
